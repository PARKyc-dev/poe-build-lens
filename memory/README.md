# Project Memory

이 디렉터리는 Codex와 이후 개발 세션이 재사용할 프로젝트 문맥을 보관한다. Git 이력을 대체하지 않는다.

## 읽기 순서

1. `active/current-context.md`
2. `active/current-decisions.md` (있을 때만)
3. 작업에 관련된 `knowledge/` 파일
4. 작업에 관련된 `decisions/` ADR

`archive/` 전체는 기본으로 읽지 않는다. 과거 맥락이 필요한 경우에만 검색한다.

## 보관 규칙

### Active

다음 몇 번의 개발 세션에 필요한 단기 작업 문맥만 둔다. 완료한 작업은 이 위치에 남기지 않는다.

### Knowledge

반복해서 유용한 사실, 아키텍처, 관례, 도메인 규칙, 인프라 가정을 둔다. 시간순 작업 로그는 보관하지 않는다.

### Decisions

의미 있는 설계 결정과 그 근거를 ADR로 보관한다. 대체된 ADR은 삭제하지 않고 `Superseded`로 표시한다.

### Archive

완료 작업의 간결한 요약을 추적성 목적으로 보관한다. 다른 곳에서 복원할 수 없는 정보가 아니라면 원본 세션 기록은 보관하지 않는다.

## 보존 원칙

미래 개발 세션이 이 정보를 몰라 잘못된 결정을 내릴 수 있다면 보존한다. 상세 과정보다 결론과 근거를 우선한다.

Git은 파일 단위 구현 이력을 담당하고, 메모리는 의도·제약·결정·재사용 지식을 담당한다.

## 정리 순서

1. 완료한 항목을 `active/`에서 제거한다.
2. 지속 지식을 `knowledge/`로 승격한다.
3. 중요한 안정된 결정은 `decisions/` ADR로 승격한다.
4. 완료 작업을 `archive/`에 간결히 요약한다.
5. 고유 정보를 보존한 뒤에만 중복·저가치 로그를 제거한다.
6. 불확실한 과거 정보는 삭제 대신 보관한다.
