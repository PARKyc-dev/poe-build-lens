# 공격 동작과 핵심 상호작용 설명 구체화

## 합의한 범위

첨부 RF PoB를 기준으로 공격의 시작·피해 발생 과정과 빌드 핵심 상호작용을 초안 수준으로 설명한다. RF 전용 문장 분기 대신 PoB의 실제 효과를 근거로 사용한다.

## 변경

- PoB 선택 공격을 후보에서 우선한다. 활성 스킬의 동작 설명과 실제 적용된 보조 효과, 계산된 레벨·퀄리티, 장비 고정 속성과 조건 설정을 전달한다.
- 다른 스킬의 보조젬, 장비·주얼·패시브·전직을 공격 설명의 출처로 사용할 수 있다. 이동기는 독립 공격으로 분석하지 않지만 버프·비용 연결 근거에 포함한다.
- 내부 수정자와 공격에 연결되지 않은 중복 흐름을 AI 입력에서 제외한다. RF 검증 입력의 프롬프트는 약 5.6만 자에서 2.8만 자로 감소했다.
- 공격별 응답 스키마가 공격 이름·출처 이름·연결된 흐름을 제한한다. 출처 설명 문장이나 다른 공격의 흐름을 넣어 전체 공격 설명이 대체되는 실패를 방지한다.
- AI 실패 시 추상적인 고정 운용 문장과 내부 수정자 목록 대신 생성 실패를 알린다. 기존 실행 로그에서 40초 HTTP 시간 초과를 확인하여 HTTP 90초/대기 95초로 조정하고 실패한 대기 작업을 취소한다.
- 속도 감소를 사용 불가로 해석하지 않도록 하고, 기본 수치를 최종 수치로 단정하지 않도록 서술 지침을 보강했다.

## 검증

- 웹 전체 테스트: 6개 파일, 31개 테스트 통과. 첨부 RF와 기존 PoB 빌드 검사 포함. 전체 실행 약 214초.
- API 전체 테스트: 45개 통과. `bootJar` 생성 성공.
- 웹 프로덕션 빌드 성공. 기존 Wasmoon의 브라우저 호환 외부 모듈 경고는 유지된다.
- 실제 PoB 추출 결과를 별도 포트 18081, 메모리 H2의 임시 서버에 보내 AI 응답과 출처 검증을 확인했다. 최종 공격별 스키마로 RF/Fire Trap의 공격 과정·상호작용 등 8개 섹션 반환을 확인했다.
- 실제 응답에서 발견한 과도한 속도 해석은 마지막 프롬프트 보강에 반영했다. 마지막 문구 보강 이후 별도 유료 생성은 반복하지 않았다. 출처 검증이 문장의 모든 게임 규칙을 증명하지는 않는다.
- 이번 작업의 임시 API·테스트 프로세스는 종료했다. 사용자가 원래 실행하던 API/Vite 서버는 유지했다. 새 API 반영에는 기존 서버 재시작이 필요하다.
