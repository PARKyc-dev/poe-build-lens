# 초기 분석기와 작업 하네스 구성

## 목표

PoE 1 Path of Building 빌드를 입력받아, 로컬에서 검토된 메커니즘을 근거와 함께 설명하는 첫 분석 흐름을 만든다.

## 완료한 사항

- 원본 PoB XML과 Base64 압축 내보내기 코드를 파싱한다.
- 빌드의 레벨, 클래스, 스킬 젬, 아이템 이름을 추출한다.
- 로컬 H2와 JPA 엔티티·리포지터리로 메커니즘 카탈로그를 조회한다.
- Fireball과 Arc 초기 카탈로그 데이터를 추가하고, 근거·수집일·검토 상태를 결과에 포함한다.
- 확인할 수 없는 스킬은 추측하지 않고 미확인으로 표시한다.
- 단일 웹 화면과 분석 API를 추가한다.
- 작업 규칙, 진행 중·완료 작업, 결정 기록을 분리하는 하네스를 구성한다.

## 검증

- `./gradlew test --no-daemon` 통과
- `./gradlew bootJar --no-daemon` 통과

## 후속 사항

- 검토된 메커니즘 카탈로그 범위를 확장한다.
- PoB 공유 URL 등 추가 입력 형식의 지원 여부를 결정한다.
