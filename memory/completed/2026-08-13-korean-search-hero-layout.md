# 한국어 검색형 히어로 레이아웃

## 목표

PoB Inspect 화면의 영문 안내를 한국어로 바꾸고, PoE Lens 제목·상태·입력창을 중앙 검색형 축으로 배치한다.

## 범위

- `web` 화면 문구와 컴포넌트 테스트
- Inspect 제목·안내 제거 및 중앙 히어로 정렬
- Worker 상태와 Inspect 동작 유지

## 완료 기준

- 사용자에게 보이는 안내 문구가 한국어다.
- `ENGINE CHECK`와 `PoB headless inspect`가 보이지 않는다.
- `PoE Lens`와 입력창이 중앙 정렬된다.
- 웹 테스트와 프로덕션 빌드가 통과한다.

## 검증 결과

- 브라우저에서 제목·상태 배지·입력창이 화면 가로 중앙에 정렬된 것을 확인했다.
- `cd web && npm test -- --run`: 5개 통과.
- `cd web && npm run build`: 통과.
