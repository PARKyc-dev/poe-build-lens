# PoB inspect 검색형 레이아웃

## 목표

PoB inspect 입력 화면을 현재 색상·톤을 유지한 Google 검색형 중앙 레이아웃으로 변경하고 Build analysis 기능을 제거한다.

## 범위

- `web`의 입력 레이아웃과 관련 컴포넌트 테스트
- 분석 입력·버튼·결과 및 관련 클라이언트 상태 제거
- Inspect API 요청·상태·결과 동작 유지

## 완료 기준

- 중앙 검색형 PoB 입력과 Inspect 버튼이 표시된다.
- Build analysis UI와 상태가 제거된다.
- Inspect 요청, 결과, 오류, 중복 요청 방지 테스트가 통과한다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-13: 사용자와 레이아웃 설계 합의 및 구현 계획 작성.
- 2026-08-13: 분석 입력·상태·클라이언트를 제거하고 Inspect 전용 중앙 검색형 레이아웃을 적용했다.
