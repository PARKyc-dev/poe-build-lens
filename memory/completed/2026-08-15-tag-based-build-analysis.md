# 태그 기반 빌드 분석

## 목표

스킬명·패시브명·아이템명별 예시 규칙을 제거하고, PoB가 계산·추출한 스킬 태그, 효과 태그, 수치 사실만으로 분석 문장을 만든다.

## 범위

- 스킬: 피해·원소·범위·투사체·운용 방식 태그
- 버프: 활성 효과 태그(예: 감전 면역, 주문 막기)
- 패시브·장비: 효과 문장에서 추출한 생명력·회복·저항·막기·피해·방어도·회피·상태 이상 태그
- API: 이름 기반 메커니즘 카탈로그 조회를 분석 경로에서 제거

## 완료 기준

- 임의의 스킬/패시브/아이템 이름에도 같은 태그 조합이면 같은 분석 구조가 생성된다.
- PoB→API 계약에 아이템 효과 태그와 버프 효과 태그가 포함된다.
- API·웹 전체 테스트와 빌드가 통과한다.
