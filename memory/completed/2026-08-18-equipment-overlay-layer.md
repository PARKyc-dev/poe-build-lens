# 장비 설명 오버레이 레이어

## 목표

PC 장비 설명을 별도 우측 칼럼이 아닌 장비창 위에 겹치는 오버레이로 표시한다.

## 범위

- 웹 장비 설명 레이어의 데스크톱 위치 스타일만 변경한다.
- 기존 호버·초점 상호작용과 모바일 상세 목록은 유지한다.

## 완료 기준

- 설명 레이어가 장비창 레이아웃의 크기나 위치를 변경하지 않고 위에 겹친다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-18: 스크린샷을 재확인해 별도 칼럼이 아닌 오버레이가 요구 사항임을 확인했다.
- 2026-08-18: 설명 레이어를 장비창 기준의 절대 위치 오버레이로 변경했다. 레이어는 슬롯 배치를 밀지 않는다.
- 2026-08-18: 빈 장비 세트에서는 슬롯 그리드를 숨기고 기존 안내 문구만 표시하도록 회귀를 수정했다.

## 검증 결과

- `cd web && npm test -- --run src/App.test.tsx`: 5개 테스트 통과.
- `cd web && npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
