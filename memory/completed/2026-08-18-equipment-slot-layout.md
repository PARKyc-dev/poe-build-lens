# 장비 슬롯 레이아웃

## 목표

PoB 분석 후 장비를 목록 카드가 아닌 장비 슬롯 위치에 맞춘 레이아웃으로 표시한다.

## 범위

- 웹 상세 화면의 장비 섹션과 스타일만 변경한다.
- 기존 PoB 장비 데이터와 아이콘이 없는 경우의 슬롯 라벨 표시를 유지한다.

## 완료 기준

- 주무기·보조 무기·투구·갑옷·장갑·장화·장신구·플라스크가 대응 위치에 표시된다.
- 장비의 이름·기본 베이스·옵션은 접근 가능한 방식으로 계속 확인할 수 있다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-18: 기존 장비 목록 카드와 PoB 슬롯 데이터를 확인했다.
- 2026-08-18: PoB가 제공하는 15개 장비 슬롯을 고정 그리드에 배치했다. 빈 슬롯도 표시하고, 기존 장비 옵션 목록은 레이아웃 아래에 유지했다.
- 2026-08-18: 코드 리뷰에서 확인된 모바일 단일 열 요구와 슬롯 접근성 이름을 반영했다.

## 검증 결과

- `cd web && npm test -- --run`: 6개 파일, 20개 테스트 통과.
- `cd web && npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
- 슬롯 UI 테스트: 주무기·플라스크가 해당 슬롯에 있고 빈 투구 슬롯이 표시되는지 확인.
