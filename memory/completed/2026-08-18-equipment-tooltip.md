# PC 장비 설명 레이어

## 목표

데스크톱 장비 슬롯에 마우스를 올리거나 키보드로 초점을 맞췄을 때, 선택 장비의 상세 정보를 게임형 레이어로 표시한다.

## 범위

- 웹 장비 슬롯과 기존 장비 상세 목록의 PC 표시만 변경한다.
- 모바일의 현재 상세 목록 동작은 유지한다.

## 완료 기준

- 장착된 PC 장비 슬롯에서 이름·베이스·옵션을 담은 설명 레이어를 열 수 있다.
- 빈 슬롯은 레이어를 열지 않는다.
- 모바일은 기존 상세 목록을 유지한다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-18: 기존 고정 장비 슬롯 레이아웃과 상세 목록을 확인했다.
