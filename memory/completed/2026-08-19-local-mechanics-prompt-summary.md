# 로컬 메커니즘과 PoB 프롬프트 요약

## 목표

AI 분석 프롬프트에 관련 로컬 게임 규칙을 제공하고, 전체 PoB 사실 대신 분석에 필요한 사실만 전송한다.

## 범위

- 태그·방어 수치에 맞는 로컬 메커니즘 규칙을 선택한다.
- 공격·방어 분석에 필요한 PoB 사실만 프롬프트에 요약한다.
- 장비·주얼 원문 옵션 전체는 전송하지 않는다.

## 완료 기준

- 지속 피해·덫·방어도 등 해당 메커니즘 규칙이 관련 빌드에 포함된다.
- 요약에는 공격·방어 핵심 사실이 남고 장비 원문은 제외된다.
- API 전체 테스트와 패키지 생성이 통과한다.
