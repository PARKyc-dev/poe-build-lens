# Log4j2 백엔드 로깅

## 목표

백엔드의 주요 분석·AI 연동 흐름을 콘솔과 파일 로그에서 확인할 수 있게 한다.

## 범위

- Spring Boot 기본 로깅 구현을 Log4j2로 교체한다.
- 분석 요청·분석 완료·AI 호출·응답 파싱·프롬프트 파일 저장의 성공·실패 경계를 기록한다.
- 프롬프트·응답 원문·API 키는 일반 로그에 기록하지 않는다.
- 프로젝트 코드가 출력하는 로그 메시지와 필드명을 한국어로 유지한다.

## 완료 기준

- `logs/api/application.log`에 분석 흐름 로그가 기록된다.
- API 전체 테스트와 패키지 생성이 통과한다.

## 검증 결과

- `cd api && ./gradlew test --no-daemon`: 통과.
- `cd api && ./gradlew bootJar --no-daemon`: 통과.
- `logs/api/application.log`에서 분석 요청 시작·AI 미사용 분기·분석 완료 로그를 확인했다.
- 프로젝트 코드의 Log4j2 메시지가 한국어로 출력되도록 변경했다.
