# 항상 활성화된 플라스크 계산

## 목표

PoB 분석에서 장착한 모든 플라스크 효과를 항상 활성 상태로 계산한다.

## 범위

- 브라우저 PoB bridge에서 장착된 플라스크 슬롯을 계산 전에 활성화한다.
- 플라스크를 기재 목록으로 추가하지 않고, 계산 수치와 방어 분석의 입력으로만 반영한다.

## 완료 기준

- XML의 플라스크 활성 상태와 관계없이 같은 방어 계산값을 반환한다.
- 웹 전체 테스트와 빌드가 통과한다.

## 진행 상황

- 2026-08-22: 장착된 플라스크 슬롯을 강제로 활성화하고, 비활성 XML fixture도 같은 계산 결과를 내는 테스트를 추가했다.

## 검증 결과

- `cd web && npm test -- --run`: 6개 파일, 27개 테스트 통과.
- `cd web && npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
