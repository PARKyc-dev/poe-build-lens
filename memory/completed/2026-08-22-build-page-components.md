# 빌드 페이지 컴포넌트 분리

## 목표

빌드 상세 화면을 스킬·패시브·장비 컴포넌트로 분리하고, 패시브 목록에 텍스트 구분을 표시한다.

## 범위

- `BuildDetailPage`에서 스킬, 패시브, 장비 UI를 각각 분리한다.
- 패시브 트리·마스터리·전직 노드 앞에 대괄호 텍스트 구분을 넣는다.
- 기존 tooltip과 장비 배치 동작을 보존한다.

## 완료 기준

- 세 영역이 독립 컴포넌트로 렌더링된다.
- `[패시브 트리]`, `[마스터리]`, `[전직 노드]`가 목록 앞에 표시된다.
- 웹 전체 테스트와 빌드가 통과한다.

## 진행 상황

- 2026-08-22: 기존 단일 페이지 컴포넌트의 스킬·패시브·장비 렌더링을 분리했다.
- 2026-08-22: 패시브 트리, 마스터리, 전직 노드 목록의 앞에 대괄호 텍스트 구분을 추가했다.

- `cd web && npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
