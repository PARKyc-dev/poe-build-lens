# 압축 메커니즘과 항목별 설명 팝업

## 목표

패시브·전직·마스터리와 빌드 기재를 간결하게 표시하고, 각 항목을 가리키거나 키보드 초점을 맞췄을 때 해당 위치 가까이에 상세 설명을 표시한다. 빌드 상세를 공격·방어·버프·패시브 트리·장비로 구분한다.

## 범위

- 웹 상세 화면에서 패시브·전직 노드를 아이콘과 이름 목록으로 압축한다.
- 장비·주얼 설명에는 모든 옵션을 표시한다.
- 장비·주얼·패시브·전직 설명 팝업을 선택 항목 가까이에 배치한다.
- 공격·방어·버프 기재에서 각각의 관련 스킬 목록과 분석 설명을 표시한다.
- 플라스크는 장비 영역에만 표시한다.
- 패시브·전직·마스터리를 서로 다른 아이콘으로 구분한다.
- 공격·방어·버프 기재도 아이콘과 이름만 표시하고 상세는 tooltip으로 옮긴다.

## 완료 기준

- 압축 항목 hover/focus 시 상세 tooltip이 열린다.
- 서로 다른 장비 슬롯의 tooltip 위치가 해당 슬롯 위치에 따라 달라진다.
- 장비·주얼의 모든 옵션이 상세 설명에 표시된다.
- 방어 기재에는 가드 스킬과 방어 태그가 있는 버프·오라만 표시된다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.
