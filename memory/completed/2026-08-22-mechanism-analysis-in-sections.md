# 기재 영역의 메커니즘 분석 표시

## 목표

공격·방어·버프 기재 목록의 맨 아래에 해당 분석 결과를 표시한다.

## 범위

- API의 공격·방어·버프 분석 결과를 각각의 기재 영역에 연결한다.
- 기존 스킬별 hover 설명은 유지한다.

## 완료 기준

- 각 기재 영역의 목록 아래에 해당 분석문이 표시된다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-22: 각 기재 영역의 하단 분석문 표시를 검증하는 화면 테스트를 추가했다.
- 2026-08-22: 공격·방어·버프 목록 아래에 각각의 API 분석 결과를 표시했다. 스킬별 PoB hover 설명은 유지했다.

## 검증 결과

- `cd web && npm test -- --run`: 6개 파일, 27개 테스트 통과.
- `cd web && npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 통과.
