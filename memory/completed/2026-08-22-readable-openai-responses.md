# 읽기 쉬운 OpenAI 응답 로그

## 목표

OpenAI 전체 응답 JSON 대신 파싱된 모델 응답을 UTF-8의 읽기 쉬운 JSON으로 프롬프트 로그에 저장한다.

## 범위

- 응답 파서가 파싱 결과를 들여쓰기 JSON으로 변환한다.
- 정상 응답은 변환한 결과를 기록한다.
- 파싱 실패 시에는 진단을 위해 원본 응답을 기록한다.

## 완료 기준

- 로그에 이스케이프된 `output_text` 대신 공격·방어 요약이 직접 표시된다.
- 파서와 전체 API 검증이 통과한다.

## 진행 상황

- 2026-08-22: 원본 Responses API JSON을 그대로 기록해 내부 JSON 문자열이 이스케이프되어 보이는 원인을 확인했다.
- 2026-08-22: 정상 응답은 파싱한 공격·방어 요약을 들여쓰기 JSON으로 기록하고, 파싱 실패 시에만 원본 Responses API 본문을 기록하도록 변경했다.
- 2026-08-22: 기존 `logs/prompt`의 4개 로그도 같은 형식으로 변환했다. 각 변환 결과에서 공격·방어 요약 JSON을 다시 파싱해 확인했다.

## 검증 결과

- `cd api && ./gradlew test --no-daemon`: 전체 테스트 통과.
- `cd api && ./gradlew bootJar --no-daemon`: 패키지 생성 통과.
