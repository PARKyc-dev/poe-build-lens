# 스킬별 툴팁과 대형 전직 노드

## 목표

공격·방어·버프 기재의 hover에 빌드 전체 분석문이 아닌 해당 스킬의 PoB 설명과 효과를 표시하고, 전직 노드는 대형 노드만 표시한다.

## 범위

- 브라우저 PoB 결과에 화면 전용 스킬 툴팁 데이터를 추가한다.
- 공격·방어·버프 목록이 해당 이름의 툴팁 데이터를 사용하도록 한다.
- 전직 노드 추출을 노터블·키스톤으로 제한한다.

## 완료 기준

- 각 목록의 hover가 각각의 고유 효과를 표시한다.
- 공통 버프 문구와 기재 전체 분석문을 재사용하지 않는다.
- 작은 전직 노드가 결과에 포함되지 않는다.
- 웹 전체 테스트와 프로덕션 빌드가 통과한다.

## 진행 상황

- 2026-08-22: 기존 툴팁이 API의 기재 전체 분석문을 재사용하는 것을 확인했다. PoB의 `GemTooltip`과 동일한 젬 설명·스탯 설명 데이터로 화면 전용 툴팁을 구성하기로 했다.
- 2026-08-22: `skillTooltips`를 브라우저 PoB 결과에 추가하고, 공격·방어·버프 기재가 해당 이름의 고유 효과만 표시하도록 변경했다. `buildFacts`는 변경하지 않아 API 요청 계약은 유지했다.
- 2026-08-22: 전직 추출을 노터블·키스톤으로 제한해 소형 전직 노드를 제외했다.
