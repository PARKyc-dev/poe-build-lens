# 기재 목록 중복 제거

## 목표

같은 이름의 기재가 여러 목록에 중복 표시되지 않게 하고, 전직 노드는 항상 전직 노드 목록에 표시한다.

## 범위

- 패시브·마스터리·전직 노드 사이의 이름 중복을 제거한다.
- 공격·방어·버프 기재 사이의 이름 중복을 제거한다.
- 전직 노드를 패시브보다 우선한다.

## 완료 기준

- 전직 이름은 전직 노드 목록에만 표시된다.
- 각 기재 이름은 공격·방어·버프 중 한 목록에만 표시된다.

## 진행 상황

- 2026-08-22: 전직 → 패시브 → 마스터리, 공격 → 방어 → 버프 우선순위로 이름을 선점하도록 변경했다.
