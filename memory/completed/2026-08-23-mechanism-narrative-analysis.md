# 메커니즘 중심 자연어 분석

## 목표

PoB 선택 주 스킬 대신 활성 피해 스킬별 합산 DPS 상위 2개를 공격 기재로 선정하고, 근거 기반의 공격·방어 설명을 OpenAI API로 생성한다.

## 범위

- 브라우저 PoB 브리지의 스킬별 `CombinedDPS` 계산과 상위 2개 선정
- API의 근거 묶음, 단일 FIFO OpenAI 생성 큐, 근거 검증 및 규칙 기반 대체
- 공격·방어 설명과 근거 중심 화면

## 완료 기준

- mainSkill 선택과 관계없이 합산 DPS 상위 2개가 주력·보조 공격이다.
- OpenAI 응답은 공격명·섹션·근거 식별자를 포함하고, 입력 근거와 불일치하거나 실패하면 규칙 문장으로 응답한다.
- API/웹 테스트와 빌드가 통과한다.

## 진행 상황

- PoB 통합 테스트를 먼저 추가했고, 활성 피해 스킬의 개별 `CombinedDPS` 순위로 상위 2개를 전달하도록 구현했다.
- OpenAI 생성 큐 및 서술 분석은 진행 중이다.
- 2026-08-23: 모든 공격 기재의 심화 분석 방향을 확정했다. PoB `skillModList`에서 실제 계산에 적용된 수정자의 이름·종류·출처·조건을 추출해 공격별 근거 그래프로 전달한다. OpenAI는 이 근거를 핵심 동작·보조젬 연결·빌드 연결·운용 방식의 섹션형 설명으로만 문장화한다.
- 2026-08-23: 적용 수정자와 지원젬 효과를 공격별 근거로 전달했다. 규칙 기반 응답은 공격별 핵심 동작·보조젬 연결·적용된 빌드 효과·운용 방식을 각각 표시하며, LLM 프롬프트도 지원젬 이름뿐 아니라 실제 효과 문구를 포함한다.
- 2026-08-23: OpenAI 응답을 공격별 구조화 섹션으로 확장했다. 응답의 공격명과 근거 식별자가 PoB 입력에 없으면 해당 OpenAI 응답 전체를 폐기하고 규칙 기반 공격 분석을 사용한다.
- 2026-08-23: `caution` 섹션을 제거했다. 지속 피해를 주는 `buffSkill`은 상시 유지형 피해로 분류해 공격 후보에 포함하고, 단일 공격 빌드는 해당 공격의 근거가 있는 섹션만 표시한다.
