# 지원하는 PoB 입력

## 결정

압축 PoB 코드, 원본 XML, `pobb.in` 공유 링크를 지원한다. 브라우저는 공유 링크에서 ID만 추출하고 동일 출처의 API에 요청하며, API가 고정된 `https://pobb.in/{id}/raw` 주소에서 원본 코드를 가져온다.

## 선택 이유

압축 코드와 XML은 브라우저에서 바로 파싱할 수 있다. `pobb.in`은 일반 공유 URL이 HTML을 반환하고 raw 응답에는 브라우저 CORS 허용 헤더가 없으므로, 서버 중계가 필요하다. 공유 ID는 영문자·숫자·하이픈·밑줄만 허용하고 대상 호스트를 코드에 고정해 임의 URL 요청을 막는다.

## 대안

브라우저가 `pobb.in/{id}/raw`를 직접 요청하는 방식은 CORS 정책 때문에 사용할 수 없다. 사용자가 raw 코드만 복사하게 하는 방식은 가능하지만 입력 편의성이 낮다.
